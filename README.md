## 🚀 Projects

**Mod-Sync-Updater** (Java, JavaFX, REST APIs, SHA-256 Hashing)
* **What it does:** A desktop client-server application for gamers that synchronizes Minecraft modifications.
* **The impact:** Simplifies the complicated process of installing game mods. It uses secure cryptographic hashing and a custom API to verify and update files automatically over the network, complete with a secure authentication dashboard for managing file uploads.
  
**Anime Notifier Bot** (Java, Spring Boot, PostgreSQL, AniList API)
* **What it does:** A notification system for Discord communities.
* **The impact:** Automatically tracks when new episodes of specific shows are released online and sends a real-time alert to the chat. This prevents users from having to constantly refresh websites to see if their show is out.

**Networked Checkers** (Java, JavaFX, Client-Server Architecture)
* **What it does:** A digital Checkers game featuring local play, online matchmaking, and real-time chat.
* **The impact:** Allows users to connect over a network to play against friends while a central server automatically synchronizes the board state, enforces complex game rules (like forced captures), and provides an accessible colorblind mode for inclusivity.

**Live Weather Dashboard** (Java, National Weather Service API)
* **What it does:** A dynamic desktop application that fetches real-time local weather forecasts, precipitation probabilities, and radar data.
* **The impact:** Automatically converts user city searches into precise geographical coordinates to pull live government weather data, wrapping it in a visually engaging interface with dynamic background videos and icons based on the current forecast.

**Still Breathing** (Godot, GDScript)
* **What it does:** A custom 2D top-down video game.
* **The impact:** Built entirely from scratch, this project brings a virtual world to life. It features smooth player movement, interactive objects, and a dynamic lighting system that changes how the environment looks as the player explores.
